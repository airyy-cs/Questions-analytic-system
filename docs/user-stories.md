# User Stories


### User Story 1: Question Bank Management

As a lecturer, I want to manage multiple-choice questions in a question bank, so that I can organize and prepare assessment questions efficiently.

Acceptance Criteria:
1. The lecturer can add, edit, and delete MCQ questions in the question bank.

2. The lecturer can categorize questions according to courses, topics, and difficulty levels.

### User Story 2: Online Assessment

 As a student, I want to complete multiple-choice assessments online, so that I can assess my understanding of the course material.



Acceptance Criteria:
1. The student can access and answer MCQ assessments assigned by the lecturer.

2. The student can submit the completed assessment, and the system automatically calculates the score.

### User Story 3: Question Analytics

As a lecturer, I want to view question analysis results through a dashboard, so that I can identify questions that require improvement.



Acceptance Criteria:
1. The system calculates the Difficulty Index and Discrimination Index based on students' responses.

2. The lecturer can view the analysis results through charts and graphs on the dashboard.
